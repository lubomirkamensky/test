## Goal

Probe the story machinery this Epic exists to exercise — mechanism under
test: the projection applicability filter (`requires_cli`, EVOLUCEAN-0287
R1) and the stop-handler per-Epic idle pattern resolution (EVOLUCEAN-0287
R2). This story (a) gives the test Epic its own idle-session pattern so the
R2 lookup has something to resolve, (b) removes the fifteen stale empty
projections (Artifacts, Capabilities, Complexity, Design-Patterns, Orphans
x epic / test-sandbox / test-jira) that 0287's filter makes generation stop
producing, and (c) records evidence that a non-evolucean Epic and its
subepics now receive only meaningful projections.

## Requirements

### R1: The test Epic has its own idle-session pattern

**Acceptance Criterion:** `_grid4d/pattern/` contains a
`test-*-idle-session-pattern.md` following the simulation frame (stories are
probes; output is evidence, not features). A live stop-handler idle status
resolved from this Epic names that pattern file, not the evolucean shaping
playbook and not the generic wildcard default.

### R2: Stale CLI-dependent projections are removed

**Acceptance Criterion:** The fifteen stale files (TEST-Artifacts.md,
TEST-Capabilities.md, TEST-Complexity.md, TEST-Design-Patterns.md,
TEST-Orphans.md under `_grid4d/_generated/epic/` and the TEST-SANDBOX-* and
TEST-JIRA-* equivalents under the subepics' `_generated/subepic/`) are
deleted from this repository, and a full projection regeneration with the
landed 0287 code does not recreate any of them while all knowledge-based
projections still generate.

### R3: Story and subepic machinery still works end to end

**Acceptance Criterion:** The story lifecycle on this Epic completes
normally from a worktree (this story itself is the evidence: create from the
main tree, worktree bootstrap, resume rebind, tests, complete via the
landing pipeline), and one subepic (test-sandbox) still resolves its story
documents and projections correctly afterwards.

## Acceptance Criteria

- [x] `test-*-idle-session-pattern.md` exists and the live idle instruction names it
- [x] Fifteen stale CLI-dependent projections deleted; regeneration does not recreate them
- [x] Story lifecycle and subepic resolution work end to end (this story completes normally)
